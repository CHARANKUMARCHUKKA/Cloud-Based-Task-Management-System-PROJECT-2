# 🚀 Cloud-Based Task Management System

A full-stack Task Management Web Application deployed on AWS EC2 using Flask and SQLite.

## 📌 Features

- User Registration & Login
- Secure Authentication
- Create Tasks
- Update Tasks
- Delete Tasks
- Dashboard Management
- Responsive UI
- Cloud Deployment on AWS EC2

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- Bootstrap

### Backend
- Python
- Flask

### Database
- SQLite

### Cloud
- AWS EC2
- Ubuntu Linux

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Move into project folder:

```bash
cd YOUR_REPOSITORY
```

Create virtual environment:

```bash
python -m venv venv
```

Activate environment:

Windows:

```bash
venv\Scripts\activate
```

Linux:

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install flask flask-mail apscheduler gunicorn
```

Run application:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
